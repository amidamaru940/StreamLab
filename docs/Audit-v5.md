# Проверка StreamLab v5 · 8 октября 2026

## Результат

Полная Debug-сборка для физического iPhone (arm64, без подписи) завершилась **BUILD SUCCEEDED**, exit 0. Использован установленный Xcode 27.0 (27A266a), iPhoneOS SDK 27.0, deployment target iOS 17.0. Подпись и установка на телефон не выполнялись.

Все семь Swift-файлов отдельно прошли проверку типов с iOS SDK без диагностик. Изначально среда блокировала запуск серверов макросов SwiftUI через вложенную песочницу. Для кросс-версийной совместимости UI использует обычный `SwiftUI.State` через псевдоним `ViewState`, а Canvas — `PreviewProvider`. Защита песочницы не отключалась. После этого штатная сборка прошла. CoreSimulator в ограниченной среде недоступен; его служебные сообщения и предупреждение об отсутствии AppIntents не помешали сборке для устройства.

## Исправления, которые проверялись

- Поворот камер: удалены фиксированные 90°, применяются отдельные системные RotationCoordinator для capture/preview. Новый вход камеры пересоздаёт координатор; селфи зеркалируется отдельно. Проверены компиляция с iOS SDK и жизненный цикл кода, **не физическое изображение с iPhone**.
- Чат: цельные разговоры вместо комбинаторных приставок/окончаний, смешанные голоса, восемь сцен, ссылки на участника в ответах. Похожие тексты отбрасываются по каноническому тексту и пересечению значимых слов.
- Камера: короткие устойчивые сигналы, более редкие повторные реакции, ручной приоритет 15 секунд. Vision-сцены требуют трёх подтверждений; нестабильный свет/движение не трактуются как конкретная история.
- Бесплатный генератор: Apple SystemLanguageModel, проверка готовности, один запрос за раз, ограниченные пакеты и контекст, отбрасывание устаревших результатов, fallback на библиотеку. Доступность реальной модели и качество её ответов на телефоне **не проверены**.
- Донаты: немного медленнее, уведомления минимум 7 секунд, FIFO и интервал 0,8 секунды, не у каждого доната есть записка. USD-распределение сохранено.
- Заголовок и имя можно редактировать прямо с экрана эфира. При смене заголовка меняется контекст локального генератора.
- Обработаны `won't` / `won’t`, повреждённый ответ вида `}{`, ссылки с заглавным HTTP и переносы строк.
