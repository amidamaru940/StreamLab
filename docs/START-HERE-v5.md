# Как передать проект Claude

В архиве находятся исходники StreamLab v5, подробная инструкция `CLAUDE.md`, согласованный план всех 38 пунктов `ROADMAP.md`, исследование, существующие проверки и макет интерфейса. Изменения из плана ещё не внедрены.

**Claude Code на Mac:** распакуйте архив в отдельную папку, откройте эту папку как проект и отправьте текст ниже. `CLAUDE.md` находится в корне рядом с Xcode-проектом.

**Обычный чат Claude:** приложите архив, если интерфейс поддерживает его чтение. Если нет — прикрепите отдельно `CLAUDE.md`, `ROADMAP.md`, исследование и файлы Swift. Один текст инструкции не даёт Claude доступ к исходникам или возможность собрать iOS-приложение; для сборки нужна доступная ему среда Mac с Xcode.

## Сообщение для Claude

Продолжи разработку моего StreamLab по приложенному проекту. Сначала полностью прочитай CLAUDE.md и ROADMAP.md, затем изучи фактические исходники и исследование. Это существующая рабочая база v5; все 38 пунктов доработки включены в план, но ещё не реализованы.

Главное для меня — ощущение настоящего живого стрима: моя реальная камера, постоянные виртуальные участники, естественные разговоры и донаты. Чат не должен выглядеть как тупые боты. Особенно важно убрать мгновенные ответы на вопросы, синхронные реакции и шаблонные цепочки. Люди должны замечать события, читать, думать и набирать сообщения с разными задержками; не каждый вопрос обязан получить ответ. При этом переписка должна оставаться связной и подходить происходящему.

Ты можешь самостоятельно улучшать проект в рамках основной задумки. Начинай с диагностики Apple Intelligence и основы нового движка: постоянные участники, память, причинность, расписание показа и устойчивый бесплатный режим. Затем выполняй остальные этапы плана. Общайся со мной по-русски, интерфейс и чат оставляй на английском. API и облако сейчас не подключай — сначала бесплатная версия.

Работай над исходниками и проверяй результат, не ограничивайся советами. Различай готовый код, успешную сборку и реальную проверку на iPhone. Сохраняй промежуточные рабочие версии, отмечай выполненные пункты и в конце дай обновлённый проект с понятной инструкцией установки. Если твоя среда не позволяет выполнить часть работы, скажи конкретно какую, не объявляя её выполненной.
